# EMAIL SEMENTARA

Aplikasi email sementara gratis — buat alamat sekali pakai, baca inbox, salin kode verifikasi.

## Cara pakai

1. Buka `index.html` (atau versi GitHub Pages repo ini).
2. Ketuk untuk membuat alamat email sementara baru.
3. Pakai alamat itu untuk daftar di situs/aplikasi yang butuh verifikasi email.
4. Kode verifikasi masuk ke inbox di aplikasi — buka pesannya dan salin kodenya.

## Tentang

- Klien gratis dari layanan **mail.tm** (API publik, tanpa kunci).
- Alamat berdomain mail.tm; banyak situs yang menolak domain email sementara.
- Jangan pakai untuk akun penting atau yang ada uangnya — inbox email sementara bukan tempat menyimpan akun berharga.
- Desain ONE HENDRIUS: tema dark elegan yang menyala, emas + cyan.

## File

- `index.html` — aplikasi lengkap (satu file, tinggal buka di browser).
